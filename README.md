# Aman Chauhan Portfolio

A responsive static portfolio website for GitHub Pages.

## Before publishing
1. Replace `your@email.com` and the phone number in `index.html`.
2. Replace the four placeholder project cards with your actual work.
3. Update the LinkedIn URL.
4. Optional: add project images/videos in an `assets` folder and link them from the cards.

## Publish with GitHub Pages
Create a GitHub repository (for example `aman-portfolio`), upload these files to the repository root, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your site will be available at your GitHub Pages URL.

## Custom domain
After buying a domain, configure it under Settings → Pages → Custom domain. Follow GitHub's current DNS instructions.
